# Family Budget Junior — prototype cliquable

Maquette interactive servant à valider les écrans et les parcours **avant** développement.
Ce n'est pas l'application : aucune donnée réelle, aucun backend, aucun appel à une IA.

**Démo :** https://Barbaag-Arch.github.io/fbj-proto/

## Contenu
- `index.html` — prototype autonome (HTML/CSS/JS, aucune dépendance hors polices Google)

## Ce que la maquette démontre
- Parent-First : les profils enfants ne se créent que depuis le compte parent
- Bascule automatique par l'âge : < 8 ans → mode Éveil visuel ; ≥ 8 ans → mode Autonomie + coach IA
- Connexion enfant par code PIN 4 chiffres, sans e-mail (code de démo : `1234`)
- Garde-fous de l'assistant IA : refus de tout sujet hors éducation financière
- Contrôle parental : désactivation de l'IA, blocage de profil, export et suppression définitive (droit à l'oubli)

## Avertissements
- Données fictives, stockées uniquement dans le navigateur du visiteur (localStorage)
- Avatars provisoires — les visuels définitifs seront acquis sous licence commerciale
- Réponses du coach IA simulées
- Le bouton « Réinitialiser » remet la démo à son état initial
